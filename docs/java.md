# Java Language Support

Java projects depends heavily on some environment variables that have to be manually changed to switch between versions.

It allows you to:

- List, install and update Java libraries 

- List, install and update Java versions from several vendors

- Self update, update java versions and libraries

- Switch between versions with a simple command:

```bash
sdk use java 25.0.4-tem
```

## The script

- Installs SDKMAN

- Installs latest stable java version from OpenJDK

- Adds update, self upgrade, update java and cleanup commands to the update.sh
