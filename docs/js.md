# JavaScript Support 

PNPM is a js/ts eviroment manager that fast and compatible with multiple enviroments.

 - Supports Node, Bun and Deno runtimes
 
 - Installs and updates multiple runtimes versions
 
 - Faster than npm and yarn
 
 - Uses less space in disk
